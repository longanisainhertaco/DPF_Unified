================================================================================
TROUBLESHOOTING
================================================================================

Issue: Blank page or nothing shows up
→ Solution: Try a different browser or clear browser cache (Ctrl+Shift+Del)

Issue: Filters not working
→ Solution: Ensure JavaScript is enabled in browser settings

Issue: Slow to load
→ Solution: This is normal for 7.5 MB on first load. Loading to memory
             takes a few seconds. Subsequent interactions are instant.

Issue: Search not finding results
→ Solution: Check spelling. Search is case-insensitive but exact-match
             for words. Try partial keywords.

Issue: Equation display looks strange
→ Solution: Some equations use special characters. Your font may not
             support them. Try a different browser or system font.

Issue: Mobile display is squashed
→ Solution: The sidebar auto-hides on small screens. You can still access
             filters from the sidebar. Pinch to zoom if needed.
