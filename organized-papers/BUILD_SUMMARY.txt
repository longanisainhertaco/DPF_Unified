1. SEARCH & FILTERS (Left Sidebar)
   - Full-text search across titles, authors, abstracts, findings
   - Category dropdown multi-select
   - Year range slider (1900-2025)
   - Domain tags checkboxes (58 domains)
   - Methodology type filters
   - One-click reset all filters

2. PAPERS TAB (Main view)
   - Sortable table: Title, Authors, Year, Category, Equation Count
   - Click column headers to sort ascending/descending
   - Click paper title to expand full details
   - Detail view includes:
     * Abstract and key findings
     * Domain tags with confidence %
     * All equations from paper
     * Methodology types
     * Related papers (cross-references)

3. DOMAIN NETWORK TAB
   - SVG-based visualization
   - 58 research domains as nodes
   - Connection thickness = relationship strength
   - Node size = paper count in domain
   - Interactive visualization

4. AI-PHYSICS LINKS TAB
   - Browse all 5,198 AI-Physics crossover connections
   - Paper pairs shown with connection details
   - Shared domains and methods highlighted
   - Click through to paper details

5. EQUATIONS TAB
   - Searchable database of 6,710 equations
   - Search by equation text or context
   - Shows source paper for each equation
   - Context preview for each equation

6. STATISTICS TAB
   - Summary cards: Papers, Equations, Cross-refs, AI-Physics links
   - Bar charts:
     * Papers by year (top 15)
     * Papers by category (all)
     * Papers by domain (top 20)
     * Most common terms (top 30)
