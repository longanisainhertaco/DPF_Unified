## 5. Method

- A-1: `missing_provenance_fields()` iterates `REQUIRED_PROVENANCE_FIELDS` (now
  including `source_packet_hashes`) and treats `None` or any empty sized
  container as missing; linter C7 re-derives the same check from the raw
  manifest dict rather than trusting `manifest.provenance_complete`.
- A-2: stale artifacts are moved under a path containing the substring
  `archive_stale_pre_ssr`, which the linter's `_exemption_reason` recognises as
  archived and reports `EXEMPT`.
- A-3: the verification gates render the report in memory; `--check` compares it
  byte-for-byte to the on-disk dated docs and exits nonzero on any
  missing/changed file without writing. Determinism is achieved by replacing the
  sub-second `generated_at_utc` wall-clock field with the date slug.
- A-4: CI runs the linter twice — `results/*.json` (active root) and
  `results/**/*.json` (recursive) — so archive-exemption logic is exercised.
- A-5: the seven ruff findings in the audit-named slice are fixed at source.
- A-7: requirement statuses are edited in `DPF_REQUIREMENTS_BASELINE.md`; the
  RTM exports are regenerated by `scripts/export_srs_traceability.py`.
